Migrate jobs → Solar-jobs

One-off tool. Makes Solar-jobs the single home for every job.

What this does

  • Copies every record in jobs into Solar-jobs with all its fields (customer name, phone, email, address, install date, engineer status…).
  • If the job is already in Solar-jobs (same document ID, or same Job Number + Job Type) it only fills in blank fields — it never overwrites anything already in Solar-jobs.
  • Otherwise it creates the Solar-jobs record using the same document ID, so existing survey links keep working.
  • Adds matching field names so every page can read every job: Install Date ⇄ Booked Date, Lead Engineer ⇄ Lead, Job Length ⇄ Days, 1st line of address → Address. This is also applied to existing Solar-jobs records (blanks only).
  • Nothing is deleted. The old jobs collection stays as a backup.
  • Safe to run more than once.
